# dsh-qq-intent-dsh

[English](README.md) | 中文

## 概要

本开发 bundle 通过 DSH 配置的模型和持久 Session 服务提供 `qqTurnIntent`。它默认关闭，需要独立的 `dsh-qq-turn-control` bundle。已运行隔离 DSH 联装、Web 设置页和小样本合成内容的真实模型判断测试；Linux、真实 QQ 和自然对话全链路仍未验证，因此不是发行候选。

## 使用与限制

将 bundle 安装到 DSH 0.2.2-rc.1 profile，并同时安装 dsh-qq-turn-control 0.1.0-development。在接话插件启用意图判断前，先在 DSH 插件管理器中的所有者设置页配置并启用本组件。`provider` 与 `model` 须同时填写，或同时留空以使用宿主模型。页面不编辑凭据，请通过宿主配置。保存要求分类器空闲，切换期间新的未明确寻址消息会暂时回退到基础规则。

安装共享消息库、聊天和接话开发包后，使用 `dsh plugin --profile <profile> add <archive.tgz>` 安装本 bundle。这些开发依赖尚未发布到公共注册表，本地测试时需提供经过校验的安装包。

只接受严格的决策 JSON；输出无效时交回聊天插件的基础规则。明确指定机器人的消息继续由聊天插件直接处理。不同群使用独立原生 Session，并可配置并发、队列、活跃 Session、输入大小和轮换限制。轮换限制用户输入字符数与轮次，不等同于模型 token 上限；淘汰或轮换后的 DSH 持久 Session 日志仍会留在磁盘并可能累积。模型仍可能误判含糊对话或受不可信文字影响，上线到真实群之前需要检查实际表现。

## 测试与隐私

`npm test` 使用合成数据，不发送 QQ 消息。分类器会把选定的群上下文文字发送给所选模型，并将模型可见输入保存在 DSH Session 日志中。接口里的成员 ID 是临时别名，但消息正文可能包含个人信息。本插件不挂载人设或 skills，媒体标记也不包含图片或音频内容。插件会抑制可选运行时上下文；宿主必需的上下文仍可能被加入，部署前须检查宿主组合。请分别保护 profile、模型凭据和 Session 存储。

调用者取消或运行时关闭后，即使模型已给出判定、后台仍在清理，本包也不会把迟到判定返回为可用结果。取消和关闭继续等待已接收工作的清理完成。
