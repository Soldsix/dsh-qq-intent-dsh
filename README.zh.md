# dsh-qq-intent-dsh

[English](README.md) | 中文

## 概要

通过宿主模型与持久 Session 服务提供仅返回接话判定的分类器。本 bundle 默认关闭，为 dsh-qq-turn-control 提供可选分类。不同群上下文使用独立且有界的 Session；明确指定仍由 Chat 处理。本 GitHub 预览提供分类服务；上游模型质量与实际 QQ 投送分别验收。

<a id="installation-and-use"></a>
## 安装与使用

目标宿主为 DSH 0.2.2-rc.1 和 Node >=24.9；Node 22 检查记录兼容性，不扩张宿主支持范围。使用 `dsh plugin --profile <profile> add <archive.tgz>` 安装归档；turn-control 0.2.0-development 从公开 GitHub 发行解析，未发布 npm。QQ 接话仍需启用 turn-control 和 Chat 运行组件。分类器本身不连接 QQ。

在 DSH 插件管理器打开本 bundle 的所有者设置页。先配置并启用分类器，再开启接话插件的意图分类。`provider` 与 `model` 要么同时填写，要么同时留空以沿用宿主路由。凭据仍由宿主凭据服务管理。修改设置要求分类器空闲；维护期间新的非指定判定返回 `default`。

<a id="decisions-and-cancellation"></a>
## 判定与取消

可信消费插件提供有界会话快照和不透明上下文 ID，不能让模型或群成员选择其他会话的上下文 ID。服务只接受严格的单字段 JSON 判定：`reply`、`ignore` 或 `default`。格式错误或多余输出返回 `default`，turn-control 0.2 将其保守地视为忽略。已知 `replyTo` 和机器人 `respondingTo` 别名帮助区分回复其他成员与新成员接续机器人的公开话题。媒体标签只说明类型。明确指定的消息绕过分类。

可配置并发、待处理数、活跃 Session、输入大小及轮换限制。同一上下文串行，不同上下文可并发推进。调用者取消或运行时关闭后，清理期间完成的迟到结果也会拒绝；卸载会等待已接收工作结束。分类器仍可能误读含糊或不可信的聊天；返回值仅为接话判定，不是事实回答或权限授权。

<a id="privacy-and-storage"></a>
## 隐私与存储

选定模型会收到群文字快照，DSH 在自身 Session 日志中记录模型可见输入。成员别名不含直接协议 ID，但正文可能带有个人信息。本插件不挂载人设或 skills，不向模型暴露工具。它抑制可选运行时上下文；宿主强制上下文仍可能存在，部署前应检查宿主组合。

轮换按输入字符和轮数计算，不等于提供方 token。淘汰或轮换会关闭活跃句柄，但保留持久 Session 日志，因此磁盘日志可能累积。请保护本机 profile、凭据服务和 Session 存储。上下文身份绑定与输出披露由消费策略负责，本服务不授权 QQ 收件对象，也不披露历史聊天。

## 模型体验

仅在可信消费插件提交快照后调用宿主模型，输入为结构化的历史与候选消息，输出仅为接话判定。分类 Agent 不挂载主聊天人设或模型工具；不会直接向 QQ 返回说明、思考或判定 JSON。最终是否回答及向谁投送由消费插件负责。

<a id="verification-and-limits"></a>
## 验证与限制

`npm run check` 严格构建 Host/Client、运行合成测试并验证发行包。源码测试包含排队取消、公平调度、Session 轮换、错误或工具输出、外部输入干扰和迟到清理结果，不向 QQ 发送消息。报告分别记录本地受控模型、真实 API 场景和实际客户端投送。

隔离 SDK、Web、消费者及组合接话脚本接受明确的发行包。每个发行包实际执行的公开版本组合与跨平台检查见发行说明。早期合成真实模型试验单独归档，不是智商对照或自然群聊基准。此处尚未验收真实 QQ、桌面端或完整媒体理解。

## 已知限制与后续工作

启用表示服务已注册，不代表上游模型已通过鉴权或质量验收。调用者须提供取消或截止信号；本包没有独立的联网、识图、长期人物记忆、QQ 发送或机器人身份识别功能。暂存快照有截断标记，分类错误仍可能发生；本次发行验收范围见上节。
